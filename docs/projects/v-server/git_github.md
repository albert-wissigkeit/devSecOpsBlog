Configuring Git User Identity and SSH Authentication for GitHub Access

## Quickstart

### 1. Configure Global Git Identity

Git attaches your username and email to every commit you make. GitHub uses the email address to associate commits with your GitHub account.

1. **Set your username:**

```bash
git config --global user.name "Your Name"
```

2. **Set your email address:**

```bash
git config --global user.email "your_email@example.com"
```

3. **Verify configuration:**

```bash
git config --list
```

---

### 2. Set Up SSH Key Pair for GitHub Access

Generate a unique SSH key pair on your VPS to securely pull and push repositories without entering credentials every time.

1. **Test GitHub SSH connection:**

```bash
ssh -T git@github.com
```

It will fail with the following message: *git@github.com: Permission denied (publickey).*

2. **Generate an SSH key pair:**
   Run the keygen command using your GitHub email address as a comment label (`-C`):

```bash
ssh-keygen -t ed25519 -C "v-server-name: your_email@example.com"
```

Press `Enter` to accept the default file location (`~/.ssh/id_ed25519`) and optionally set a passphrase.

3. **Display and copy your public key:**

```bash
cat ~/.ssh/id_ed25519.pub
```

4. **Add the public key to GitHub:**

- Copy the output generated by the `cat` command.
- Go to GitHub: **Settings** -> **SSH and GPG keys** -> **New SSH key**.
- Paste the key, give it a title (e.g., `VPS Server Lab`), and click **Add SSH key**.

5. **Test your GitHub SSH connection:**

```bash
ssh -T git@github.com
```

If successful, you will see a message: _Hi ! You've successfully authenticated..._

## Description

### What You Can Do with GitHub Access

- **Clone Private Repositories:** Pull code securely from your private repositories to your VPS via SSH (`git clone git@github.com:username/repo.git`).
- **Push Code & Changes:** Commit and push updates or deployments directly from the server back to GitHub without re-entering credentials.
- **Automate Server Deployments:** Enable smooth continuous integration (CI/CD) workflows or automated pull scripts (e.g., via cron jobs or webhooks) to update production/staging environments.

### Key Concepts

- **Git User Identity (`user.name` & `user.email`):**
  These values act as the author signature on every commit history entry. Setting them ensures your contributions on the server correctly link to your GitHub profile.
- **`-C` Parameter:**
  Adds a plain-text comment (server-name and your email) at the end of the public key, making it easy to identify which machine or account the key belongs to.
